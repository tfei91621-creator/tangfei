## GitHub Pages
将本目录的内容推送到公开仓库main分支。在Settings → Pages中将Source设为Deploy from a branch，选择main及/(root)，保存。保留.nojekyll文件。

如果使用普通仓库名portfolio，地址由GitHub提供，形式为https://实际用户名.github.io/portfolio/。不要将该示例当作已发布地址。

所有资源使用相对路径，兼容仓库子路径。不要上传外层site文件夹作为额外层级；index.html应在发布根目录。

本仓库仅用于展示作品，品牌概念设计及AI辅助内容说明见各项目，不代表品牌官方委托。未经权利人许可不得再分发作品素材。
